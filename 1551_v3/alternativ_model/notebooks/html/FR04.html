FR04 — Əsas məhsul növlərinin natural göstəriciləri¶

Əsas məhsul növlərinin sahələr üzrə natural göstəricilərinin proqnozlaşdırılması, o cümlədən aksizli məhsullar (MİİS §15.5.1, bənd 2.4.1.4.).

1. Tələb¶

Spesifikasiyanın mətni (§15.5.1, FR4): "Əsas məhsul növlərinin sahələr üzrə natural göstəricilərinin proqnozlaşdırılması (o cümlədən aksizli məhsullar)."

Tələb aqreqat dəyər göstəricisi deyil, natural (fiziki) ölçü vahidləri ilə ifadə olunan məhsul buraxılışının proqnozunu nəzərdə tutur: min ton buğda, min ton sement, QVt.s elektrik, min baş mal-qara və s. Statutar şablonun 2.4.1.4. vərəqi bu göstəriciləri 179 sətirdə, altı geniş sahə üzrə (bitkiçilik/heyvandarlıq, mədənçıxarma, emal sənayesi, elektrik-qaz-su təchizatı, nəqliyyat, rabitə) toplayır və mötərizədəki qeyd ("o cümlədən aksizli məhsullar") bu 179 məhsulun içində aksizli mal qruplarının (alkoqollu içkilər, tütün məmulatları, neft məhsulları, avtomobillər) da olduğunu bildirir — ayrıca bir alt-siyahı deyil.

Bu FR-in əsas metodoloji çətinliyi say deyil, şablonun özünün bütövlüyüdür: 179 sətirin 10 adı 23 sətirdə təkrarlanır (məsələn "Avtomobil" həm yük daşınmasında — mln ton, həm yük dövriyyəsində — mlrd t-km görünür) və 272 xana #REF! qaytarır, o cümlədən bir sətrin (179) adının özü. Aşağıdakı bölmələr bu iki qüsuru struktur səviyyəsində necə bağladığını göstərir, sonra 178 istifadə edilə bilən məhsul üçün ayrı-ayrılıqda sürücü təyinatı, qiymətləndirmə və proqnoz aparılır.

2.1. #REF!-ölü 11 qida məhsulunun dirçəldilməsi (bu buraxılış)¶

Bu buraxılışa qədər 48–58-ci sətirlərin hər biri yalnız beş real il (2013–2017) daşıyırdı və n_eff<8 qaydası onları avtomatik SABİT (2017-ci ilin dəyərində düz xətt) kateqoriyasına yönləndirirdi — yəni on bir qida məhsulunun 2018-dən sonrakı bütün dinamikası modeldən kənarda qalırdı.

DATA_GAP_NEGATIVE_PROOF.md sənədinin (vii) bəndi bu on bir sətrin DSK qarşılıqlarını xana səviyyəsində təsbit edib: sənaye məhsullarının natural ifadədə istehsalı üzrə cədvəl 18 (018en.xls, 1995–2024) və ət/süd üçün kənd təsərrüfatı cədvəlləri 1.46 / 1.47 (1.46en.xls, 1.47en.xls, 1985–2024). Sıralar data_layer §14-ün dondurulmuş açıq-mənbə panelindədir və vereq_product_concordance() hər şablon sətrini öz DSK mənbəyi, mənbənin etiketi, vahidi və çevirmə əmsalı ilə birlikdə qaytarır.

Birləşdirmə qaydası (nə üçün məhz belə). DSK sırası şablonun sətri ilə eyni anlayış deyil (məsələn 1.47 xam süd istehsalını verir, şablon isə emal edilmiş duru südü); ona görə DSK-dan səviyyə deyil, dinamika götürülür və sıra şablonun öz son ortaq ilinin (2017) səviyyəsinə yenidən bazalaşdırılır:

$$Q^{\text{yeni}}_t = Q^{\text{şablon}}_{2017}\times\frac{S^{\text{DSK}}_t}{S^{\text{DSK}}_{2017}}$$

Bu, iki qüsuru eyni anda bağlayır: ölçü vahidi fərqi (ton → min ton) və anlayış fərqi (xam/emal edilmiş) — hər ikisi sabit əmsal olduqda tam, dəyişkən olduqda isə ölçülə bilən qalıqla. Ona görə hər sətir üçün ortaq illərdə (2013–2017) nisbətin sabitliyi yoxlanılır və qərar bu yoxlamanın nəticəsinə görə verilir: nisbətin variasiya əmsalı (CV) 5 %-dən böyükdürsə, sıra dirçəldilmir və SABİT qalır.

RATIO_CV_MAX = 5.0            # QAPI-2a: nisbətin sabitlik həddi, %
ANCHOR_ID_TOL = 1.0           # QAPI-2b: lövbər ilində eynilik həddi, %

REBASED, revive_rows = {}, []
for _, cr in CON.iterrows():
    _row = int(cr["vereq_row"])
    _Qt = data_layer.vereq_actuals("2.4.1.4.", cr["vereq_name_az"], row=_row)
    _S = data_layer.public_series(cr["series_code"])
    _com = sorted(set(_Qt.index) & set(_S.index))
    _rat = (_Qt.loc[_com] / _S.loc[_com]) if _com else pd.Series(dtype=float)
    _cv = float(_rat.std() / _rat.mean() * 100) if len(_rat) > 1 else np.nan
    _has_anchor = (REBASE_ANCHOR in _Qt.index) and (REBASE_ANCHOR in _S.index)
    _anch = float(_Qt.loc[REBASE_ANCHOR] / _S.loc[REBASE_ANCHOR]) if _has_anchor else np.nan

    # QAPI-1: ölçü vahidi uzlaşırmı (konkordansın xana səviyyəsində yoxlanmış `factor` sahəsi)
    _g1 = bool(pd.notna(cr["factor"]))
    # QAPI-2a: mütənasiblik — ortaq illərdə nisbətin variasiyası kiçikdir
    _g2a = bool(len(_rat) > 1 and _cv <= RATIO_CV_MAX)
    # QAPI-2b: lövbər eyniliyi — lövbər ilində iki sıra EYNİ ədəddir (şablonun ÖZ tərif
    # sınığı ortaq pəncərəni pozduqda 2a keçmir, lakin lövbərdə eynilik dirçəlişi əsaslandırır)
    _g2b = bool(_has_anchor and abs(_anch - 1.0) * 100 <= ANCHOR_ID_TOL)

def log_growth(Q):
    # Sıfır dəyərli illər loqarifmə keçmədən NaN kimi işarələnir və atılır — sıfır heç vaxt
    # süni artım kimi şərh olunmur.
    q = Q.replace(0, np.nan)
    return np.log(q).diff().dropna()


CAP_PCT = 12.0          # illik tavan (%) — ETALON üsulunda hər tavanlanma aşağıda cədvəldə göstərilir
PLAUSIBILITY_PCT = 25.0  # GATE-i keçən STRUKTUR tənliyinin belə hörmətə layiq olması üçün üst hədd:
                         # kiçik nümunədə (n=11) statistik əhəmiyyət təsadüfən keçilə bilər, lakin
                         # nəticə 6 illik üfüqdə iqtisadi cəhətdən inandırıcı olmalıdır — orta illik
                         # nəzərdə tutulan artım bu hədddən kənara çıxarsa, tənlik RƏDD edilir və
                         # ETALON üsuluna keçilir (aşağıda hər hal açıq hesabat olunur).


def median_growth_capped(dlq):
    win = dlq.loc[(dlq.index >= 2019) & (dlq.index <= 2024)]
    if win.empty:
        win = dlq
    med_log = float(win.median())
    med_pct = (np.exp(med_log) - 1) * 100
    capped_pct = float(np.clip(med_pct, -CAP_PCT, CAP_PCT))
    capped_log = float(np.log(1 + capped_pct / 100.0))
    return med_pct, capped_pct, capped_log

def eq_latex(res, driver_label, lhs="\\Delta\\ln Q_t"):
    b, se_b = res.params["x"], res.se["x"]
    c, se_c = res.params["const"], res.se["const"]
    sign = "+" if b >= 0 else "-"
    body = (r"\underset{(" + f"{se_c:.4f}" + r")}{" + f"{c:.4f}" + "}"
           + f" {sign} " + r"\underset{(" + f"{se_b:.4f}" + r")}{" + f"{abs(b):.4f}" + r"}\," + driver_label)

        def _fn(train, target_year):
            d = train.dropna()
            if len(d) < 6:

            if target_year not in driver_series.index:

            xv = float(driver_series.loc[target_year])
            return float(res_v.params["const"] + res_v.params["x"] * xv)

Bu, digər FR-lərin 2025 faktiki dəyərlərinə malik olması ilə uyğunsuzluq yaradır və dashboard istifadəçisi bunu nəzərə almalıdır.

DEVIASİYA (sürücü təyinatı): brifin nəzərdə tutduğu "uyğunsuz məhsullar üçün SEKTORUN FR2 artımı sürücü kimi" qaydası hərfi tətbiq oluna bilmədi, çünki FR2 (istehsal strukturu) bu tikinti dalğasında (Wave D, paralel qrup) FR4 ilə eyni vaxtda qurulur və D2 DAG-ına görə FR4 ondan asılı DEYİL. Bunun əvəzinə hər bölmə kodu FR1 nüvəsinin dörd mövcud yolundan (neft, qeyri-neft, investisiya, istehlak) birinə birbaşa təyin edilib — kənd təsərrüfatı, mədənçıxarmanın digər sahələri, kommunal, nəqliyyat və rabitə sahələri üçün bu, nonoil_realg aqreqat yolu ilə vəkalətçi (proksi) əlaqədir, sahə-səviyyəli dəqiq deyil. FR2 gələcəkdə əlavə olunarsa, bu 62 məhsulun (nonoil_realg sürücülü) təyinatı sahə-səviyyəli artıma yüksəldilə bilər.

nonoil_realg sürücüsünün tarixi və proqnozu eyni tərif üzərində deyil. Sürücünün faktiki hissəsi statutar sıradır (bazar qiymətləri; bütün mədənçıxarma neft blokunda), proqnoz hissəsi isə assumptions.csv-in nonoil_realg açarıdır və istehsal metoduna keçiddən sonra o, FR02-nin aşağıdan-yuxarı ƏLAVƏ DƏYƏR aqreqatıdır (qeyri-neft mədənçıxarma qeyri-neft blokunda). İki bazanın fərqi FR02, Bölmə 7.4-də sətir-sətir ölçülür (2017–2025 üzrə orta mütləq fərq ~0,5 f.b.). Bu sürücü ilə qiymətləndirilən tənliklərin əmsalı statutar baza üzərində, proqnoz yolu isə istehsal hesabı bazası üzərində olduğu üçün 62 məhsulun yolunda kiçik, lakin sistematik bir uyğunsuzluq qalır; ölçüsü məhsul səviyyəsindəki qeyri-müəyyənlikdən xeyli kiçikdir.

Panel sınağının şərtiliyi. Bölmə 6-nın STRUKTUR modeli proqnoz anında sürücünün həmin ilki faktiki dəyərini bilir, RW etalonu isə bilmir. Bu, proqnozdakı istifadə rejimi ilə eynidir (sürücü fərziyyə yolu ilə verilir), lakin bacarıq rəqəmini STRUKTUR-un xeyrinə çevirir. Paketin FR01 dəftəri eyni vəziyyəti şərti/şərtsiz ayrımı ilə nəşr edir; FR4-də panel kiçik olduğu üçün ayrıca ex-ante variant hesablanmır, şərtilik isə açıq qeyd olunur.

Bant (yelpik zolağı) qərarı. Paketin özünün presedentinə uyğun olaraq (FR1-in gdp_nom, oil_nom və s. səviyyə sıraları da bant daşımır, yalnız artım tempi sıraları daşıyır), FR4-ün 178 natural göstərici SƏVİYYƏSİ forecast_long.csv-də bant DAŞIMIR — çünki hər məhsul üçün ayrıca artım-tempi series_code yaratmaq (356 sıra) miqyas baxımından qeyri-mütənasib olardı. Parametr və qalıq qeyri-müəyyənliyi STRUKTUR tənliklərinin HAC standart xətası (equations_catalog.csv) və təmsilçi panelin geriyə doğru sınaq RMSE-si (validation_backtest.csv) vasitəsilə hesabat edilir, lakin hər məhsulun səviyyə yolu üçün ayrıca lo80/hi80 YOXDUR.

Aksizli mallar təsnifatı yaxınlaşmadır. Bölmə 7-dəki aksiz cədvəli Azərbaycanın aksiz qanunvericiliyinin ümumi kateqoriyalarına (alkoqol, tütün, neft yanacaqları, avtomobillər) əsaslanır, dəqiq hüquqi maddə-maddə siyahı deyil.
